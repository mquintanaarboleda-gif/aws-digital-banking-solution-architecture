# Portfolio Disclaimer

This repository is an **independent, anonymized solution-architecture case study** created for professional portfolio purposes.

The scenario name **Banco Digital Ecuador** is generic. The repository does not represent an official, deployed or approved architecture of any financial institution and contains no customer records, credentials or production secrets.

Technology choices, RTO/RPO values, latency targets, security controls and regulatory considerations are architecture proposals from the exercise. A real implementation would require formal validation by business owners, enterprise architecture, cybersecurity, risk, privacy, legal, compliance, operations and the relevant regulators.
